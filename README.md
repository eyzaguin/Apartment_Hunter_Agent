```text
my-apartment-agent/
├── api/
│   └── search.py

```

## Deployment Steps
1. Push this folder to a GitHub repository.
2. Go to Vercel.com, click **Add New Project**, and import your repository.
3. Vercel will automatically detect the configuration and deploy your live public URL!
